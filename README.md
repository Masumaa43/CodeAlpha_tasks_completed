# Credit Scoring Model

## Overview
A machine learning project that estimates loan-default risk
using borrower and loan information.

## Technologies
- Python
- Pandas
- Scikit-learn
- Logistic Regression
- Streamlit
- Matplotlib
- Seaborn

## Features
- Data preprocessing
- Missing-value handling
- Categorical encoding
- Numerical feature scaling
- Model training
- Model evaluation
- Confusion matrix and ROC curve
- Interactive Streamlit interface

## Dataset
Place the dataset at:

dataset/credit_risk_dataset.csv

The target column should be named `loan_status`.
