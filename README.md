# Handwritten Character Recognition System

## Objective
To identify handwritten digits and English alphabets
using image processing and deep learning.

## Dataset
EMNIST ByClass

- Digits: 0-9
- Uppercase: A-Z
- Lowercase: a-z
- Total classes: 62

## Technologies

- Python
- TensorFlow
- Keras
- CNN
- OpenCV
- NumPy
- Pandas
- Streamlit
- Matplotlib

## Model Architecture

- Convolutional Layers
- Batch Normalization
- ReLU Activation
- Max Pooling
- Dropout
- Dense Layers
- Softmax Output

## Features

- Handwritten digit recognition
- Uppercase alphabet recognition
- Lowercase alphabet recognition
- Image upload
- Prediction confidence
- Model performance visualization
