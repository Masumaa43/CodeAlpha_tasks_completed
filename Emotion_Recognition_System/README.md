# Emotion Recognition from Speech 

## 📌 Project Overview

Emotion Recognition from Speech is an AI and Deep Learning project that identifies human emotions from speech recordings.

The system uses **MFCC (Mel-Frequency Cepstral Coefficients)** for audio feature extraction and a **Convolutional Neural Network (CNN)** to classify different emotions.

An interactive Streamlit dashboard allows users to upload audio files, listen to recordings, visualize audio signals, and view predicted emotions with confidence scores.

## 🎯 Objectives

* Recognize human emotions through speech.
* Extract audio features using MFCC.
* Train a CNN-based emotion classification model.
* Predict emotions from uploaded WAV audio files.
* Develop an interactive dashboard using Streamlit.

## 😊 Emotions Detected

The system supports eight emotion categories:

1. Neutral
2. Calm
3. Happy
4. Sad
5. Angry
6. Fearful
7. Disgust
8. Surprised

## 📊 Dataset

This project uses the **RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song)** dataset.

Dataset details:

* 1,440 speech recordings.
* 24 professional actors.
* 8 emotion cat
